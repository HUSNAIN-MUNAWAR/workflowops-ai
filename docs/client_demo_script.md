# Client Demo Script

1. Start with the problem: invoices, RFPs, emails, and tickets arrive in messy formats and decisions are hard to audit.
2. Upload a synthetic invoice or RFP document.
3. Show extracted fields, confidence, warnings, and document classification.
4. Open the workflow timeline and show node-by-node execution.
5. Show the policy decision: risk score, threshold, approval requirement, and matched rule.
6. Move to the reviewer approval queue.
7. Approve the request and show the run resume from the approval node.
8. Download the generated report.
9. Run Workflow EvalBench and show that not every scenario passes perfectly.
10. Open audit logs to prove who did what and when.

Close honestly: this is demo-mode architecture. A paid implementation would connect the client's systems after security and process discovery.
