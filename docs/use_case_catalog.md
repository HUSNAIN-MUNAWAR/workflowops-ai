# Use Case Catalog

## Invoice approval

Extract invoice fields, detect duplicates/mismatches, check PO/vendor data, request approval, and export a payment-ready demo report.

## Email-to-task

Classify emails, extract urgency and entities, create tasks, draft responses, and require approval before sending.

## RFP/proposal automation

Extract requirements, create compliance matrices, detect missing documents, assign sections, and generate submission checklists.

## Compliance evidence

Map synthetic PR/CI/policy evidence to controls, detect gaps, and generate audit-ready reports.

## Support escalation

Classify tickets, detect anger/refund/legal/VIP risk, recommend escalation, and produce root-cause summaries.

## Reliability testing

Simulate workflow failures and unsafe actions before connecting real tools.
