# LinkedIn Post Template

I built WorkflowOps AI - a governed AI workflow automation platform for turning messy business inputs into auditable, human-approved automations.

It is not a chatbot demo. It includes:

- Persisted DAG workflow execution
- Human approval gates
- Tenant-level policy decisions
- Safe demo connectors
- Document extraction
- Reliability/red-team workflow tests
- Audit logs and reports
- FastAPI + SQLAlchemy + Next.js architecture

The project uses synthetic data and clearly labels demo behavior. The goal is to show how AI automation can be designed safely before real connectors and production systems are added.
